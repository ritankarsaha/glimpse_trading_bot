Glimpse Kelly Bot

QLS-LMSR prediction market trading bot. API is live — use the endpoints below or launch TUI mode.

TUI Mode

./glimpse-bot --tui --model lognormal --annual-vol 65 --kelly 0.25
./glimpse-bot --tui --model gaussian  --sigma 5    --kelly 0.25
./glimpse-bot --tui --model http://localhost:9000/forecast --kelly 0.25
FlagDefaultDescription
--modelgaussiangaussian | skewed | uniform | lognormal | http(s)://… | /path/to.json
--annual-vol65.0Annualised BTC vol in % (used by gaussian & lognormal when vol+time available)
--sigma5.0Gaussian σ as % of spot — fallback when annual-vol is not set
--kelly0.25Kelly fraction (0 < c ≤ 1; 0.25 = quarter-Kelly)

POST /api/start — payload

{
  "topic_id":       1116,
  "contracts":      1,
  "poll_sec":       60,
  "max_trades":     5,
  "dry_run":        true,
  "min_expiry_mins": 10,
  "max_wallet_pct": 10,
  "no_duplicates":  true,

  // Kelly mode — omit "model" to use strategy mode instead
  "model":          "lognormal",   // gaussian | skewed | uniform | lognormal | https://…
  "model_url":      "",            // HTTP forecaster URL — overrides "model" when set
  "annual_vol_pct": 65.0,          // annualised vol in %; 0 = use config default
  "kelly_fraction": 0.25,
  "min_edge":       0.005,
  "max_bins":       10,

  // Strategy mode (when "model" is empty)
  "strategy":       "nearest"      // nearest | feargreed | bestodds | followcrowd
}

Quick test commands

# 1. Check server is up
curl http://localhost:3002/api/ping

# 2. (Optional) override the API key — the server already loads one from
#    GLIMPSE_API_KEY / config.json at startup, so this is only needed to switch keys live
curl -X POST http://localhost:3002/api/apikey \
  -H 'Content-Type: application/json' \
  -d '{"api_key":"glp_live_YOUR_KEY_HERE"}'

# 3. Start Kelly bot with log-normal model (dry run)
curl -X POST http://localhost:3002/api/start \
  -H 'Content-Type: application/json' \
  -d '{"model":"lognormal","annual_vol_pct":65,"kelly_fraction":0.25,"dry_run":true}'

# 4. Start Kelly bot with external HTTP model
curl -X POST http://localhost:3002/api/start \
  -H 'Content-Type: application/json' \
  -d '{"model_url":"http://localhost:9000/forecast","kelly_fraction":0.25,"dry_run":true}'

# 5. Check bot state (model_name, kelly_trades, logs visible here)
curl http://localhost:3002/api/status | python3 -m json.tool

# 6. Stop bot
curl -X POST http://localhost:3002/api/stop
